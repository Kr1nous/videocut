# 剪辑台：AE 常用合成能力落地（精简版）

依据备忘录《Adobe After Effects（AE）完整功能说明》，**删掉非常复杂、短视频/口播里很少用的部分**。剪辑台继续是简洁 NLE：选项卡 + 检查器；人点的按钮 = MCP = `cutstudio`。

**不要跳过阶段 1。** 现在滤镜/裁切/变速多半只在预览上，导出仍是 concat。

---

## 明确不做（备忘录里有、本计划删掉）

| 删掉 | 原因 |
|---|---|
| 父子链接、图层分组、多 Comp 嵌套/预合成 | 工程结构过重，口播成片几乎不用 |
| 贝塞尔蒙版动画、蒙版跟踪 | 建模复杂，矩形/椭圆够用 |
| 完整图表编辑器、表达式、ExtendScript | 给专业动效师用；AI 已有 MCP |
| 文字动画器全套、路径文字、木偶 | 打字机/标题预设就够 |
| 修剪路径/合并路径等形状工厂 | 不做 MG 软件 |
| 2.5D/摄像机/灯光、C4D/glb、相机反求 | 三维管线，不是本产品 |
| 点跟踪、人脸跟踪 | 算法重、场景少 |
| 逐帧 Roto | 人力工具，不是 AI 剪辑主路径 |
| VR 360、PR/PS 动态链接、Character Animator、AE 插件 | 生态绑定，不自研 |
| EXR、多机渲染 | 电影流程，用不到 |

---

## 仍要做的（常用 + 能导出）

| 能力 | 阶段 |
|---|---|
| 预览 = 导出的真合成（变换、滤镜、透明、转场、变速、裁切） | 1 |
| 多层画面 + 混合 + 调整层（没有嵌套 Comp） | 2 |
| 矩形/椭圆蒙版 | 3 |
| 关键帧（位移/缩放/透明，缓动，冻结/倒放） | 4 |
| 标题/打字机/下三分之一、简单形状 | 5 |
| 可渲染特效：调色、LUT、模糊、发光、颗粒、常用转场 | 6 |
| 稳像、绿/蓝幕抠像 | 7 |
| 波形、音量关键帧、跟鼓点（可选） | 8 |
| 导出队列、透明通道、代理 | 1 打底，9 收尾 |

现有 53 个 MCP 剪辑工具全部保留。

---

## 阶段 1 — 真合成内核（先做）

ClipFx 必须进渲染图，否则后面全是假的。

- 变换：位置、缩放、旋转、不透明度（先静态）
- 现有滤镜/裁切/翻转/淡化/转场/调色/变速真正参与预览和导出
- Viewer 采样合成帧；导出不再纯 concat
- 工程宽高、fps；导出可带 Alpha

完成：0.5 透明 + 鲜艳滤镜 + 1.5x，预览和 mp4 一致；溶解/淡黑出现在成片里。

---

## 阶段 2 — 多层与调整层

- 时间线可叠多层视频/图片（不只有 B-roll 一条）
- 混合：正常 / 相加 / 滤色 / 正片叠底
- 调整层：效果作用于下方全部层
- 纯色层
- **不做** 父子、预合成、多 Comp

工具：`add_layer` `set_blend` `add_adjustment_layer` `add_solid`。

完成：两段叠化 + 调整层降饱和，导出正确。

---

## 阶段 3 — 简单蒙版

矩形、椭圆；加/减；羽化。预览里画。

工具：`add_mask` `set_mask` `remove_mask`。

完成：椭圆露出主体、下层看得见，导出有效。

---

## 阶段 4 — 关键帧（够用就停）

位移、缩放、透明可打关键帧；线性 / 缓入缓出；冻结帧、倒放。

**不做** 曲线编辑器、时间重映射曲线。

工具：`set_keyframe` `freeze_frame` `reverse_clip`。

完成：透明 0→1→0 导出正确。

---

## 阶段 5 — 标题与简单图形

文字图层：字体、字号、颜色、描边；预设：打字机、淡入、下三分之一。矩形/椭圆色块。独立字幕轨不拆。

工具：`add_text_layer` `animate_text {preset}` `add_shape`。

完成：AI 调一次 `animate_text` 能导出 3 秒标题。

---

## 阶段 6 — 常用特效（可导出）

注册表，检查器里调参。

调色（含 LUT）、高斯/径向模糊、发光、颗粒、马赛克、溶解/淡黑/淡白/推。

工具：`add_effect` `list_effects` `apply_lut`。

完成：模糊 + LUT，预览 = 导出。

---

## 阶段 7 — 稳像与抠像

- 稳像（ffmpeg vidstab/deshake）
- 绿/蓝幕抠像：容差、溢色、边缘

**不做** 跟踪、Roto。

工具：`stabilize` `key_color`。

完成：手持更稳；绿幕能叠背景。

---

## 阶段 8 — 音频补强

波形；音量关键帧；可选 `link_to_audio`（缩放/发光跟鼓点）。降噪轻量即可。

完成：波形看得见；跟鼓点导出有效（若做）。

---

## 阶段 9 — 导出收尾

队列、H.264、透明 MOV/ProRes、半分辨率代理。

**不做** 序列帧工厂、EXR、多机。

工具：`render_queue_add` `make_proxy`。

---

## 顺序

```
1 内核 → 2 多层 → 3 蒙版
              → 4 关键帧 → 5 标题
                         → 6 特效
                         → 8 音频
         → 7 稳像/抠像（1 之后即可，不依赖 4）
1 的导出 → 9 队列/代理
```
